# AI Agent에게 일 제대로 시키는 법 배우기

일본어 교양 수업에서 매주 배운 단어와 문법을 **복습 학습지**로 만들어 주는 AI 스터디 도우미 "**하루**"를 설계하고, 모델 3종 비교부터 프롬프트 개선까지 기록한 미션 결과물입니다.

## 과업 정의

매주 일본어 교양 수업이 끝나면, 초급 대학생(타겟 사용자)이 그날 배운 단어 목록(단어 / 읽는 법 / 뜻) 10개 안팎과 문법 포인트 1\~2개를 텍스트로 넣으면(입력 데이터 형태), AI가 ① 단어장 표 ② 문법 설명 2\~3줄 ③ 예문 3개 ④ 확인 퀴즈 5문항(읽는 법 2, 뜻 2, 작문 또는 해석 1) ⑤ 퀴즈 정답으로 이루어진 복습 학습지(출력 규격)를 만든다. 자세한 정의는 [system-design.md 1장](docs/system-design.md#1-과업-정의)에 있다.

## 주요 결과

- **환각 검증:** 질문 5건, Pass 5 / Fail 0. 대화에서 환각과 문맥 끊김은 나타나지 않았다. (검증표: [system-design.md 7-2](docs/system-design.md#7-2-환각-검증표))
- **프롬프트 개선:** Few-shot을 넣자 "하루"로서 말하는 느낌이 사라져서, v2에서 인사 규칙과 예시를 고쳐 되살렸다.
- **발견한 점:** claude.ai의 메모리 기능 때문에 다른 채팅의 조건이 새 채팅에 끼어드는 일이 있어서, 메모리 생성을 끄고 다시 실험했다.
