# 미해결 기록

프롬프트를 고쳐도 끝내 원하는 결과를 얻지 못한 과업을 남긴다. 각 실행의 대화 원문은 [run-log.md](run-log.md)의 "추가 실행" 섹션에 있다.

---

## [미해결 1] 같은 자료를 주면 학습지가 매번 똑같이 나오게 하기

### 원하는 결과

같은 제2과 자료를 새 채팅에서 다시 넣어도 예문과 퀴즈가 똑같이 나와서, 친구와 같은 학습지를 공유하거나 나중에 같은 학습지로 다시 풀 수 있게 하고 싶었다.

### 처음 발견한 곳

16턴 대화에서 1턴과 같은 자료를 15턴에 다시 보냈을 때, 단어장은 같았지만 예문과 퀴즈 문장은 모두 달라졌다.

### 시도한 프롬프트

프롬프트 v2의 [규칙]에 아래 규칙 8을 추가했다. (규칙 6·7도 함께 들어 있다)

```
8. 같은 자료를 받으면 예문과 퀴즈를 언제나 똑같이 만들어. 예문과 퀴즈에 쓸 단어는 단어 목록 순서대로 앞에서부터 골라.
```

### 받은 결과

| 시도 | 실행 | 결과 |
|---|---|---|
| 1차 | 2026-11-21 18:39, Claude Opus 5.5, 새 채팅 A·B에 같은 메시지 | 퀴즈 1~4번은 같아졌지만, 예문 3개·퀴즈 5번·객관식 보기·인사가 A와 B에서 달랐다 |
| 2차 | 2026-11-21 18:43, Claude Opus 5.5, 새 채팅 A·B에 같은 메시지 (규칙 9 추가) | 퀴즈 5문항과 보기는 모두 같아졌지만, 문법 설명의 "주의" 내용과 예문의 조사(朝、/ 朝は)는 여전히 달랐다 |

### 막힌 이유 (직접 작성)

"단어 목록 순서대로 골라"처럼 정해 준 부분은 순서대로 잘 나왔지만, 정해 주지 않은 부분(예문 문장, 문법 설명)은 결국 LLM이 확률이 높은 토큰을 골라 생성하는 방식이라 매번 달라진 것 같다. 규칙을 두 번 고쳐서 퀴즈까지는 같게 만들었지만, 문장 하나하나까지 프롬프트로 고정할 방법은 찾지 못하고 여기서 멈췄다.

## [미해결 2] 무료 모델(ChatGPT)에서 「○時に」 예문 만들기

### 원하는 결과

매주 쓰려면 무료 모델이 좋아서, Claude에서 다듬은 최종 프롬프트로 무료 ChatGPT에서도 오늘 문법 「時間 + に (~시에)」를 「7時に起きます」처럼 시각과 함께 연습하는 예문을 받고 싶었다.

### 처음 발견한 곳

2026-11-21 18:35, Claude에서 규칙 6(예문·퀴즈에도 목록 단어만 쓰기)을 넣자 숫자가 목록에 없다는 이유로 「○時に」 예문이 아예 빠졌다.

### 시도한 프롬프트

규칙 6에 숫자 예외를 넣었다.

```
6. 예문, 퀴즈, 정답에도 단어 목록에 있는 단어만 써. 목록에 없는 단어나 합성어(예: 朝ご飯, 私)는 쓰지 마. 단, 〜時 앞에 붙는 숫자(1~12)는 목록에 없어도 써도 돼.
```

### 받은 결과

2026-11-21 18:45, ChatGPT GPT-6 (무료), 새 채팅에 위 규칙이 들어간 최종 프롬프트를 그대로 넣었다.
인사·단어장·퀴즈 배분은 지켰지만, 예문이 朝に起きます / 昼にご飯を食べます / 夜に水を飲みません뿐이고 단어 10번 〜時는 예문과 퀴즈에 한 번도 나오지 않았다.
(같은 프롬프트가 유료 Claude에서는 통했다. 그 실행 기록은 run-log.md에 있다.)

### 막힌 이유 (직접 작성)

유료 모델은 깊게 생각하고 답하는 것 같은데, 무료 모델은 답변이 진짜 3초면 다 나온다. 이 차이 때문에 같은 프롬프트라도 숫자 예외 같은 세부 규칙을 놓친 것 같다. 무료 모델에서도 쓰려면 프롬프트를 더 꼼꼼하게 따로 만드는 게 좋을 것 같은데, 이번에는 거기까지 시도하지 못하고 여기서 멈췄다.
